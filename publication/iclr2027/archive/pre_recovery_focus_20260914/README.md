publication files before the recovery-focused revision of 2026-09-14.

`iclr2027_sources.zip`. The `manuscript/` directory retains the old text,

`publication/iclr2027/` location. They are preserved verbatim and may not resolve
from this archival directory. Do not run the archived build tools in place.

For the current paper, return to `publication/iclr2027/README.md`.
